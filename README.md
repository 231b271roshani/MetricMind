# MetricMind – Agentic Semantic BI Engine

## 📌 Project Overview

MetricMind is an AI-powered Business Intelligence (BI) platform that allows users to analyze business data using natural language questions instead of writing SQL queries manually.

The system helps users understand important business metrics such as Revenue, Cost, Profit, and Profit Margin through conversational interactions and visual dashboards.

The main objective of MetricMind is to make business data analysis easier, faster, and more accessible while maintaining consistency and governance in business metric calculations.

## 🎯 Objectives

- Enable users to ask business questions in natural language.
- Convert user questions into structured analytical requests.
- Use predefined business metrics for consistent calculations.
- Generate meaningful insights from business data.
- Display analytical results through interactive dashboards and charts.
- Improve transparency and reliability in business reporting.

## ✨ Key Features

- **Natural Language Queries:** Ask questions about business performance using simple English.
- **AI-Powered Analysis:** Use an AI agent to interpret questions and coordinate analysis.
- **Semantic Layer:** Define standardized metrics such as Revenue, Cost, Profit, and Profit Margin.
- **Interactive Dashboard:** Display key performance indicators (KPIs) and visualizations.
- **Data Integration:** Connect the application to a PostgreSQL database.
- **Business Insights:** Support analysis of revenue, costs, profitability, and performance trends.
- **Governance and Consistency:** Use standardized metric definitions to help maintain consistent results.

## 🏗️ System Architecture

The project follows a modular architecture:

1. **Frontend:** Provides the user interface for asking questions and viewing results.
2. **Backend API:** Receives user questions and processes requests.
3. **AI Agent / Orchestrator:** Interprets user intent and coordinates analytical tasks.
4. **Semantic Layer:** Defines business metrics and dimensions consistently.
5. **Database:** Stores the business data required for analysis.
6. **Visualization Layer:** Presents results using KPI cards, charts, and tables.

### Architecture Flow

User Question → Frontend → Backend API → AI Agent → Semantic Layer → Database → Analytical Result → Dashboard

## 📊 Business Metrics

MetricMind focuses on important business performance indicators, including:

- **Revenue:** Total income generated by the business.
- **Cost:** Total expenses associated with business operations.
- **Profit:** Revenue minus Cost.
- **Profit Margin:** Profit expressed as a percentage of Revenue.

Formulas:

- Profit = Revenue − Cost
- Profit Margin = (Profit / Revenue) × 100

## 🚀 Getting Started

### Prerequisites

Install the following tools before running the project:

- Node.js and npm
- Python, if required by the backend
- PostgreSQL
- Git

### 1. Clone the Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd <YOUR_PROJECT_FOLDER>
```

### 2. Set Up the Frontend

Navigate to the frontend directory:

```bash
cd frontend
npm install
npm run dev
```

If your project uses a different directory structure, run these commands from the directory containing `package.json`.

The frontend will typically be available at:

`http://localhost:3000`

### 3. Set Up the Backend

Navigate to the backend directory and install the dependencies listed in the project's requirements file.

For a Python backend with `requirements.txt`:

```bash
pip install -r requirements.txt
```

Start the backend using the command configured in your project.

For example, if the project uses FastAPI and an application entry point named `main.py`:

```bash
uvicorn main:app --reload --port 8000
```

The backend API endpoint used by the frontend is:

`http://127.0.0.1:8000/query`

### 4. Configure PostgreSQL

- Start the PostgreSQL database server.
- Create or select the project database.
- Configure the database connection using environment variables.
- Ensure the required tables and business data are available.

Never commit database passwords, API keys, or other secrets to GitHub.

### 5. Run the Application

Start the backend and frontend in separate terminals. Open the frontend in your browser and submit a business-related question to test the application.
